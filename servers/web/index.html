四步完成接入

从注册到设备可用，链路可预期

1

创建账号与 CA

初始化根 CA 或接入既有中间 CA，配置签发策略与模板。

2

提交证书申请

填写主体与扩展信息，按域名、邮箱或组织资料完成验证。

3

签发与托管

证书签发后写入云端智能卡，私钥不出服务端。

4

设备端调用

安装 PKCS#11 驱动，现有业务系统无需改造即可签名解密。

平台能力

面向私有化部署与云端服务两种形态，模块可独立启用。

虚拟智能卡

三种安全等级的虚拟卡片：TPM 高安全、本地中安全与口令低安全。 私钥由云端托管，卡 PIN 与账号二次验证双重保护签名操作。

PKCS#11 KSP 离线缓存 端到端加密备份

证书生命周期

根 CA 与中间 CA 管理、模板化签发、CRL / OCSP 吊销服务以及 ACME 自动化签发，链路完整可追溯。

多类型凭据

统一管理 X.509 证书、SSH 密钥、GPG 证书、TOTP / FIDO 认证、登录信息与安全笔记。

云端同步

证书与元数据安全同步至云端卡片，支持离线缓存、自动重连与加密私钥备份恢复。

安全架构

AES-256-GCM 三层加密、Argon2id 密钥派生、TPM 硬件保护、JWT Token 轮换与 RBAC 权限控制。

支持的证书类型

按验证等级与用途选择，签发后可直接写入云端智能卡。

SSL/TLS 证书

面向网站与 API 网关，支持 DV / OV / EV 三种验证等级。

serverAuth

代码签名证书

codeSigning
