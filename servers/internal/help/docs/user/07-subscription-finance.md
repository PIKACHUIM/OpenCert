# 财务、优惠与订阅

以上功能都已合并到 **控制台 → 账号信息管理**，在「财务与订阅」选项卡中统一操作。

## 余额与充值

- 查看可用余额、累计充值、累计消费；
- 点击「充值」选择金额与支付渠道；
- 未接入在线支付渠道时，可线下转账后由平台管理员在「订单管理 → 确认到账」中入账。

## 优惠码

- 在商品购买页或收银台填写优惠码，系统即时显示抵扣金额；
- 支持「立减金额」与「折扣（可设封顶）」两种形式，可能有最低消费门槛、适用商品、总量与每人使用次数、有效期限制；
- 订单取消后优惠码次数会自动归还。

## 订阅套餐

订阅套餐 = 在订阅周期内，对指定的证书类型拥有固定张数额度：

- 购买：账号信息管理 → 财务与订阅 → 选择套餐 → 立即购买，走正常支付流程，**支付完成后额度自动开通**；
- 兑换：使用兑换码可直接获得订阅；
- 使用：在「证书申请 → 申请证书」的第一步选择「订阅额度」，即可用额度申请证书（不额外收费）；
- 查看：卡片上显示每个证书类型的已用/总张数、剩余张数、到期时间；
- 审核与有效期：单张证书的有效期由套餐规定（并受颁发模板允许值约束）；是否需要人工审批仍由证书开通模板决定；
- 吊销：套餐可设置「是否允许自行吊销」与「吊销后是否释放额度」，请以套餐说明为准。

## 兑换码

- 在「财务与订阅」中输入兑换码即可兑换余额或订阅；
- 每个兑换码有总可用次数与有效期，同一用户对同一兑换码只能兑换一次。

## 退款

- 待支付订单可直接取消（自动归还库存与优惠码次数）；
- 已支付订单在「我的订单」中申请退款，由管理员审批；渠道支持原路退回，余额支付退回账户余额；
- **已开卡或已提交证书申请的订单不能自助退款**，如需退款请联系客服；
- 订阅套餐订单在额度开通后即视为已履约，同样不支持自助退款。
