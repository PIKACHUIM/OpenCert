# 选购与支付

## 平台的两种申请模式

平台管理员可以分别为 **证书** 和 **云端智能卡** 设置申请模式：

| 模式 | 含义 | 您需要做什么 |
|---|---|---|
| 销售模式 | 需要先购买并支付订单 | 在产品中心选购 → 支付 → 凭订单申请证书或开通智能卡 |
| 自助模式 | 可直接申请，无需购买 | 在控制台「申请证书」或「智能卡片管理」中直接操作 |

控制台会根据当前模式自动显示或隐藏对应入口：例如智能卡为销售模式且您没有可用订单时，「创建智能卡」按钮不会出现，而是提示前往选购。

## 选购与下单

1. 门户顶栏 **产品中心**，按分类浏览 SSL 证书、代码签名证书、邮件证书、文档签名证书与云端智能卡。
2. 进入商品详情，对比不同套餐的价格、服务期、支持的密钥算法与含域名数。
3. 点击 **立即购买**，选择购买数量并填写联系邮箱（默认使用账号邮箱）。
4. 页面右侧显示的金额由服务端实时计算，最终以订单金额为准。
5. 点击 **提交订单** 后进入收银台。

> 下单时会为您预留库存；如果订单取消，库存会自动归还。

## 支付方式

收银台会列出当前可用的支付方式：

- **账户余额**：余额充足时可直接支付，立即生效。
- **在线支付渠道**（如管理员已启用）：生成支付链接或二维码，支付完成后页面自动刷新状态；也可点击「我已完成支付，刷新状态」。
- **免费订单**：金额为 0 时直接完成，无需支付。

如果收银台只显示余额且余额不足，说明平台暂未开通在线支付，请联系平台方获取**线下转账**方式；财务确认到账后，订单会被标记为已支付，您会在「我的订单」中看到状态变化。

## 订单状态

| 状态 | 含义 | 可进行的操作 |
|---|---|---|
| 待支付 | 已下单未付款 | 去支付、取消订单 |
| 已支付 | 已付款，尚未提交申请/开卡 | 提交证书申请 / 开通智能卡、申请退款 |
| 申请中 / 审核中 | 已提交证书申请 | 等待审核；多份订单可继续提交剩余份数 |
| 已完成 | 已全部签发或开卡 | 在证书或智能卡页面使用 |
| 已取消 | 待支付时取消 | — |
| 已退款 | 退款已完成 | — |

## 取消与退款

- **取消**：仅「待支付」订单可取消。
- **退款**：「已支付」且**尚未开卡、尚未提交证书申请**的订单，可在「我的订单」点击 **退款** 提交申请，由管理员审核。
  - 余额支付的订单，退款退回账户余额；
  - 在线渠道支付的订单，原路退回（以渠道处理结果为准，失败时会显示失败原因）；
  - 线下转账的订单，由财务线下退回。
- 证书申请被驳回后，订单会回到「已支付」，您可以修改资料后重新提交，也可以申请退款。
