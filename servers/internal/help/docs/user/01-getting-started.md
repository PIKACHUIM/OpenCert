# 快速开始

本平台提供数字证书（SSL/TLS、代码签名、邮件、文档签名）的选购、申请、签发与交付，以及可远程使用的**云端智能卡**。

## 1. 注册与登录

1. 点击门户右上角 **注册**，填写用户名、邮箱与密码（至少 8 位）。
2. 注册成功后自动登录并进入控制台。
3. 忘记密码时，在登录页点击 **忘记密码**，系统会向注册邮箱发送 6 位验证码。

> 所有购买与申请都需要登录后操作，订单与证书会归属到您的账号，便于续期与管理。

## 2. 开启两步验证（推荐）

账号可以绑定动态口令（TOTP）作为第二因素：

1. 控制台右上角头像 → **个人中心** → **两步验证**。
2. 使用验证器应用（如 Google Authenticator、Microsoft Authenticator）扫描二维码。
3. 输入应用中显示的 6 位验证码完成绑定。

开启后，每次登录在输入密码后还需要输入动态验证码。本地管理端（客户端）登录云端账号时同样会要求输入验证码。

## 3. 控制台菜单说明

| 菜单 | 用途 |
|---|---|
| 平台概览 | 账号下的证书、智能卡与订单概况 |
| 申请证书 | 证书申请向导：选择订单/订阅/自助 → 主体 → 域名/邮箱/IP → 确认提交 |
| 我的证书申请 | 跟踪申请进度、查看驳回原因、吊销已签发证书 |
| 智能卡片管理 | 开通、查看云端智能卡，管理 PIN/PUK/Admin Key |
| 我的证书 | 查看、下载、续期已签发的证书 |
| 支付订单管理 | 查看订单状态、去支付、提交申请、申请退款 |
| 证书主体信息 | 提交组织/个人主体信息，按模板完成审核或实名认证 |
| 证书扩展信息 | 添加域名、邮箱、IP 并完成所有权验证 |
| 账号信息管理 | 账号资料、安全设置、云端公钥、**余额/充值/退款与订阅（含兑换码）** |
| 帮助中心 | 平台使用文档（即本页） |

## 4. 典型流程一览

```
注册登录 → 选购并支付（或自助申请）→ 准备主体信息与域名/邮箱验证
        → 提交证书申请 → 审核（部分证书免审）→ 自动签发 → 下载或在智能卡中使用
```
