# 申请与签发证书

证书中的信息必须真实可验证。平台要求：**主体信息按其验证方式通过审核/实名认证**，**域名/邮箱/IP 完成所有权验证**，申请时只能引用这些已核验且未过期的信息。

## 申请入口

三种入口都会进入同一个向导：

| 入口 | 说明 |
|---|---|
| 控制台 → 证书申请管理 → 申请证书向导 | 手动选择订单、订阅额度或自助申请 |
| 支付完成页 → 去提交申请 | 购买后立即开始填写资料 |
| 控制台 → 支付订单管理 → 提交申请 | 稍后再提交时使用 |

向导共四步：**选择来源 → 主体信息 → 扩展信息 → 确认提交**。

## 第一步：选择来源

- **订单**：销售模式下，选择一笔「已支付」且仍有剩余份数的订单；
- **订阅额度**：已购买/兑换的订阅套餐，选择其中的证书类型（显示剩余张数）；
- **自助申请**：站点开启自助模式时可直接选择证书类型，无需先下单。

## 第二步：主体信息

是否出现这一步、需要填写哪些字段，由该证书类型绑定的**主体模板**决定：

- **人工审核**字段：提交后由管理员审核（通常 1 个工作日内）；
- **自动接口**字段：提交后进入「待实名认证」，点击「实名认证」跳转第三方完成核验；
- **免验证**字段：提交即生效；
- **派生字段**（如 CN 取自第一个域名）：无需填写、无需单独审核，系统在提交申请时自动推导。

主体信息审核/认证通过后有**有效期**（模板可设为 1d/7d/30d/365d 或长期），过期后需重新提交。被驳回时会显示原因，修改后可重新提交。

> 纯 DV 场景（模板只需域名）不会出现主体信息步骤，系统直接以第一个已验证域名作为证书通用名称（CN）。

## 算法与交付方式

算法由商品与证书类型共同决定，页面只会列出可选范围内的算法。

- 国密 **SM2** 固定配 **SM3**，不能单独选择其它摘要；
- 选择 SM2 时只能下载 PEM / PKCS#8，**不提供 PKCS#12**；
- 需要把证书装进智能卡或使用手机/电脑的加密设备时，请选择对应的交付方式；
- 交付方式与算法不匹配时（例如 SM2 + PKCS#12），提交阶段会直接提示。

## 第三步：扩展信息（域名 / 邮箱 / IP）

勾选已验证且未过期的项目，或在向导内直接添加并完成验证：

| 类型 | 验证方式 | 操作 |
|---|---|---|
| 域名 | DNS TXT | 添加 TXT 记录：主机 `_opencert.域名`，值为 `opencert-verify=<令牌>`，生效后点击「立即验证」 |
| 域名 | HTTP 文件 | 放置 `http://域名/.well-known/pki-validation/<令牌>`，内容为令牌，点击「立即验证」 |
| 域名 | TLS-ALPN | 在 443 端口以 ALPN `acme-tls/1` 返回含 `SHA-256(令牌)` 的 acmeIdentifier 扩展证书（RFC 8737） |
| 邮箱 | 邮箱验证码 | 系统发送 6 位验证码（15 分钟内有效，连续输错 5 次需重新发送），在向导中输入完成验证 |
| IP | HTTP 文件 | 同域名 HTTP 方式 |

页面顶部会显示**本证书允许的数量与格式**（域名/邮箱/IP 各几个、是否允许通配符、IPv4/IPv6、邮箱或域名后缀限制），超出限制的项目无法勾选。

若某项显示「需重新验证」，说明它此前是按免验证策略通过的，而本证书要求验证所有权，点击「重新验证」按当前要求完成即可。

## 第四步：确认提交

- **密钥算法**：在模板允许的范围内选择，密钥在云端智能卡或托管容器内生成，私钥不出服务端；
- **自带 CSR（可选）**：提交本地生成的 CSR，私钥始终在您手中；CSR 中出现的所有名称必须已通过本次验证；
- **存放位置**：云端使用型证书必须签入您的智能卡（可在本步选择），下载型证书存入系统「证书托管容器」。

## 审核与签发

- 证书开通模板**关闭人工审批**时：资料通过后立即签发，页面直接进入结果页，可在「我的证书申请」查看；
- **开启人工审批**时：状态为「审核中」，管理员通过后自动签发；
- 被驳回时显示驳回原因，修正资料后可重新提交（订单份数不会被消耗）。

## 下载与使用

控制台 → **我的证书管理**：

- 下载证书（PEM/DER）与证书链；
- 存储策略允许时可导出 PKCS#12（.pfx），导出需设置至少 8 位保护口令；
- 签入云端智能卡的证书，可通过本地管理端与 PKCS#11/KSP 驱动在应用中直接使用。

## 吊销

- 普通证书：控制台 → 我的证书管理 / 我的证书申请 → 「吊销」，选择原因后立即生效（CRL 会同步刷新，OCSP 实时生效）；
- 订阅套餐内的证书：是否允许自行吊销由套餐设置决定；套餐若配置「吊销后释放额度」，吊销后会归还订阅张数。
