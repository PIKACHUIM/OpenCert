# 云端智能卡

云端智能卡把私钥加密保存在平台服务端，签名、解密等运算也在服务端完成，私钥不会下发到终端设备。您的设备通过**本地管理端**和 **PKCS#11 / KSP 驱动**像使用实体 U 盾一样使用它。

## 开通智能卡

控制台 → **智能卡片管理** → **创建智能卡**：

- **自助模式**：可直接创建，每个账号可开通的数量由平台设定；
- **销售模式**：需要先在产品中心购买「云端智能卡」并完成支付；创建时选择对应订单，一笔订单可开通的数量等于购买份数。

如果页面没有「创建智能卡」按钮，说明当前不满足开通条件，页面会提示原因（例如需要先购买）。

## 三级密钥：PIN / PUK / Admin Key

| 密钥 | 用途 | 建议 |
|---|---|---|
| PIN | 日常使用口令，签名、解密、导入证书前必须验证 | 必填，至少 6 位 |
| PUK | PIN 被锁定后用于解锁并重设 PIN | 强烈建议设置，并妥善保管 |
| Admin Key | 最高权限，可重设 PIN 与 PUK | 建议设置，离线保存 |

- PIN 连续输错达到上限（默认 3 次）后卡片被**锁定**；
- 使用 **PUK 解锁** 可重设 PIN；
- PUK 遗失时，可用 **Admin Key** 同时重设 PIN 与 PUK；
- 三者都遗失时，请联系平台管理员核实身份后协助处理。

验证 PIN 后会建立一段有效期内的授权会话，期间无需重复输入；退出登录会立即失效。

## 证书托管容器

「文件下载型」证书或使用自带 CSR 申请的证书，会存入系统自动创建的**证书托管容器**。它只用于存放证书：

- 不计入智能卡开通数量；
- 不支持远程签名、解密、导入证书或生成密钥；
- 不能删除（避免连带删除已签发的证书）。

需要远程使用的证书，请在申请时选择签入您的云端智能卡。

## 在本地设备中使用

1. 在门户 **下载与接入** 页面下载并安装本地管理端与驱动。
2. 在本地管理端添加云端卡片，填写平台地址并使用平台账号登录：
   - 账号开启了两步验证时，登录后需要输入动态验证码；
3. 应用（浏览器、签名工具、邮件客户端等）通过 PKCS#11 或 Windows KSP 访问卡片时：
   - 以 `用户名:密码` 形式登录时，建立账号会话；
   - 以纯数字/字符形式输入时，作为**卡片 PIN** 校验，用于授权签名与解密。
4. 网络中断时，本地会显示缓存的证书信息，但签名与解密需要联网。

## 常见问题

- **提示需要 PIN 授权**：先在应用或本地管理端输入卡片 PIN。
- **提示卡片已锁定**：使用 PUK 解锁，或用 Admin Key 重置。
- **证书显示已吊销/已过期**：请在控制台续期或重新申请；本地管理端同步后会更新状态。
