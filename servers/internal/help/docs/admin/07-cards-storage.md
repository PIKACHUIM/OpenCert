# 智能卡存储与用户智能卡

## 1. 存储区域（私钥放在哪里）

入口：**服务配置 → 存储区域配置**。

存储区域决定卡片的私钥**存放在哪里、由谁执行密码运算**。一张卡片绑定一个存储区域；开卡后卡内所有密钥都落在该区域。

| 类型 | 私钥位置 | 能否导出私钥 | 适用场景 |
|---|---|---|---|
| 本地加密存储（database） | 服务端数据库，主密钥 AES-256-GCM 加密 | 可以（导出 PFX / PKCS#8 需授权） | 默认；需要备份私钥、交付 PFX 的下载型证书 |
| TPM（tpm2） | 本机 TPM 芯片内，密钥**永不以明文离开芯片** | 不可以 | 高安全等级：签名私钥托管在服务器且不可被拷走 |
| HSM / USB 令牌（pkcs11） | 硬件安全模块或 USB 令牌（如 SafeNet eToken 5110） | 不可以 | 合规要求私钥必须由硬件保护、需要离线可插拔的设备 |

### 1.1 新建存储区域

1. 点击「新建存储区域」，填写名称；
2. 选择「私钥存储驱动」——列表由服务端下发，包含该驱动支持的配置项与**厂商预设**；
3. HSM 驱动可先点「扫描本机 HSM」，自动发现已安装的 PKCS#11 模块（eToken / SoftHSM / YubiKey / tpm2-pkcs11）并一键填入路径；
4. 填写令牌 PIN（**加密保存，不会回显**）；
5. 点击「测试连接」确认能识别到设备，再保存。

保存后可在列表中点击「检测」随时复检连接状态，最近一次检测结果会显示在列表中。

### 1.2 使用要求

- **HSM/TPM 存储区域建议开启「允许在设备内生成密钥」**（默认开启）：私钥在硬件内生成，安全等级最高；
- 需要把已有私钥写入 HSM 时，必须显式开启驱动配置里的「允许导入外部私钥」，且设备本身要支持导入；
- TPM 出于安全模型**不支持导入外部私钥**，只能「在 TPM 内生成 → 由 CA 签发证书」；
- 设备（USB 令牌）被拔掉或换机器时，该区域下的证书无法签名/解密，列表里的「检测」会给出明确提示；
- 删除存储区域前必须先迁移或删除使用它的卡片（系统会拦截）；
- 私钥不可导出的存储区域**不能导出 PFX**：交付下载型证书时请选择本地加密存储区域。

### 1.3 扩展更多厂商驱动

无需改代码即可接入新厂商设备：

1. 在内置驱动的「厂商预设」中通常已包含常见模块路径；
2. 若使用其它模块，把 PKCS#11 动态库路径直接填入「PKCS#11 模块路径」即可；
3. 需要把它固化为团队共享的预设时，在服务端 `configs/keybackends.json` 中登记（见下例），重启后「扫描本机 HSM」即可发现：

```json
{
  "presets": [
    {
      "id": "mytoken",
      "name": "自研令牌 2000",
      "driver": "pkcs11",
      "params": { "library": "C:\\Vendor\\mytoken.dll", "keygen": "true" },
      "search_paths": ["C:\\Vendor\\mytoken.dll"]
    }
  ]
}
```

> 兼容性说明：服务端会自动识别模块的 PKCS#11 结构体对齐方式（自然对齐 / 1 字节打包），无需手工配置。

## 2. 用户智能卡管理

入口：**个人业务中心 → 智能卡片管理 → 全部用户智能卡**（管理员登录后出现该选项卡），可查看全部用户的卡片、所属用户、卡内证书数、PIN 状态、来源订单与托管容器。

| 操作 | 说明 |
|---|---|
| 解除锁定 | 清零 PIN 错误计数并解除锁定，用户仍使用原 PIN。仅在核实用户身份后操作 |
| 删除 | 连带删除卡内全部证书，**不可恢复**；删除前请先吊销仍在使用的证书 |

所有管理员操作都会写入审计日志。

## 3. 卡片类型

| 类型 | 说明 |
|---|---|
| 用户智能卡 | 用户开通，受业务模式约束；支持远程签名/解密，必须设置 PIN（至少 6 位） |
| 证书托管容器 | 系统为每个用户自动创建一个，存放下载型/自带 CSR 证书；不计入开卡数量，禁止远程密码运算、导入、生成密钥，用户不能删除 |

## 4. 安全建议

- 需要在智能卡上远程签名的证书，请让商品规格的交付方式为「云端智能卡」，或在开通模板中绑定使用云端交付的规格；
- 指导用户设置 PUK 与 Admin Key（见《云端智能卡》），避免只能找管理员解锁；
- 定期在审计日志中检查 `admin_unlock_card`、`admin_delete_card` 操作；
- 远程签名接口要求有效的 PIN 会话，会话有效期内用户无需重复输入 PIN，账号登出会立即失效。

## 5. 密钥存储模板（证书模板管理 → 密钥存储模板）

存储区域决定"私钥放在哪"，密钥存储模板则决定"密钥怎么生成、怎么交给用户"。颁发模板引用一个密钥存储模板后，签发与交付都按它执行。

| 配置 | 可选项 | 作用 |
|---|---|---|
| 存储区域 | 上文任一存储区域 | 该模板下所有私钥都落在同一个区域 |
| 密钥生成位置 | 服务端存储区域 / 用户自带 CSR / 智能卡上生成 | 决定签发时是平台生成密钥、用用户公钥，还是在卡内生成 |
| 下发方式 | 文件下载 / 云端智能卡 / 实体智能卡 / 虚拟智能卡 | 决定证书最终以什么形式交付；选择"智能卡上生成"时至少要选一种卡类下发方式 |
| 下载格式 | PEM / PKCS#12 | 仅文件下载需要；私钥不可导出的区域、以及 SM2 证书都不提供 PKCS#12 |
| 虚拟卡安全等级 | 标准 / 高 | 高等级下私钥不可导出、不可云端备份 |
| 允许重新导入 | 开 / 关 | 用户能否把外部私钥导入卡内 |
| 云端备份 | 开 / 关 | 是否允许平台托管私钥副本 |
| 重新下发次数 | 整数，-1 为不限 | 限制用户重复下发同一张证书的次数 |

> 交付时的校验顺序：先看证书的存储区域是否允许导出，再看密钥存储模板的下载格式，最后按商品规格的交付方式执行；三者不一致时会在提交阶段直接报错，不会签出无法交付的证书。
