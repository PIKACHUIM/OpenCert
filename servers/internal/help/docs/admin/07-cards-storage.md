# 智能卡存储与用户智能卡

## 1. 存储区域

入口：**服务配置 → 存储区域配置**。

| 类型 | 说明 |
|---|---|
| 数据库 | 私钥使用主密钥 AES-256-GCM 加密后存入数据库（缺省） |
| HSM | 预留：填写 HSM 驱动标识，用于后续接入硬件安全模块 |

用户开卡时可选择存储区域；未选择时使用数据库存储。停用的区域不可用于新卡。

## 2. 用户智能卡管理

入口：**个人业务 → 智能卡片管理 → 全部用户智能卡**（管理员登录后出现该选项卡），可查看全部用户的卡片、所属用户、卡内证书数、PIN 状态、来源订单与托管容器。

| 操作 | 说明 |
|---|---|
| 解除锁定 | 清零 PIN 错误计数并解除锁定，用户仍使用原 PIN。仅在核实用户身份后操作 |
| 删除 | 连带删除卡内全部证书，**不可恢复**；删除前请先吊销仍在使用的证书 |

所有管理员操作都会写入审计日志。

## 3. 卡片类型

| 类型 | 说明 |
|---|---|
| 用户智能卡 | 用户开通，受业务模式约束；支持远程签名/解密，必须设置 PIN（至少 6 位） |
| 证书托管容器 | 系统为每个用户自动创建一个，存放下载型/自带 CSR 证书；不计入开卡数量，禁止远程密码运算、导入、生成密钥，用户不能删除 |

## 4. 安全建议

- 需要在智能卡上远程签名的证书，请让商品规格的交付方式为「云端智能卡」，或在开通模板中绑定使用云端交付的规格；
- 指导用户设置 PUK 与 Admin Key（页面内的使用说明已移至帮助中心《云端智能卡》），避免只能找管理员解锁；
- 定期在审计日志中检查 `admin_unlock_card`、`admin_delete_card` 操作；
- 远程签名接口要求有效的 PIN 会话，会话有效期内用户无需重复输入 PIN，账号登出会立即失效。
