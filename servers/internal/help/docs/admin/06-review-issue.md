# 审核与签发

审核权限：**操作员（operator）及以上角色**。

## 1. 身份认证审核（主体信息 / 扩展信息）

入口：**证书颁发管理 → 身份认证审核**，两个选项卡：

- **待审核（人工）**：主体信息（含「人工审核」字段）与扩展信息（该类策略为人工审核）的审核队列，可切换对象与状态；「通过」即放行并写入有效期，「驳回」需填写原因（会展示给用户，用户可修改后重提）；
- **自动审核（认证接口）**：配置邮件接口（SMTP / Resend）与实名认证接口（通用实名回调；支付宝、微信为预留插件位），内置的域名 DNS/HTTP/TLS 与邮箱验证码无需配置。

详细规则见《身份认证审核与自动审核接口》。

核验要点：

- 组织名称与营业执照一致；国家使用两位代码；
- EV/OV 类需核对组织真实性（线下材料、第三方企业信息查询）；
- 个人证书核对姓名与身份；
- 审核/认证通过后按模板有效期生效，过期后需用户重新验证。

## 2. 证书申请审核

入口：**证书颁发管理 → 证书申请审核**。申请包含：

- 主体：来自已审核主体信息，或 DV 场景下的第一个已验证域名；
- SAN：来自用户已验证且未过期的域名/邮箱/IP；
- 密钥：云端生成（记录算法）或自带 CSR（CSR 中的名称已由系统校验必须全部经过所有权验证）；
- 目标卡片：云端使用型证书签入用户指定的智能卡；下载型证书签入用户的系统托管容器。

操作：

- **通过**：立即调用签发引擎签发并落库；多份订单在全部份数签发后才会完成；
- **驳回**：必须填写原因；订单回到「已支付」，用户可修正后重新提交或申请退款。

### 免审自动签发

证书开通模板关闭「需要审批」时，用户提交后系统以 `system` 身份自动审批并签发（签发结果页会提示「证书已签发」）。若签发失败（例如 CA 不可用、模板配置不完整），申请保持「待审核」，用户看到「已转人工处理」，管理员在审核列表中处理。

> 注意：关闭审批不等于放宽资料要求——主体信息仍需按其验证方式通过审核/实名认证，扩展信息仍需已验证且未过期，否则提交会被拒绝。

## 3. 签发失败排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 无法确定签发 CA | 开通模板与颁发模板都未指定 CA | 在开通模板或颁发模板中指定 CA |
| 所选商品已下架 | 证书开通模板被停用 | 启用模板，或让用户改用其它订单 |
| 不支持所选密钥算法 | 用户选择的算法不在模板白名单 | 调整模板或让用户重新提交 |
| 有效期 90 天不在模板允许列表 | 订阅套餐/规格设置的单证有效期与颁发模板不一致 | 调整颁发模板允许列表或套餐/规格设置 |
| 目标智能卡不存在 | 用户删除了卡片 | 驳回并说明原因 |
| 所选主体信息尚未审核通过 / 审核已过期 | 主体信息状态不满足 | 在「身份认证审核」中处理，或让用户重新提交验证 |

## 4. 吊销

- **证书颁发管理 → 全部证书管理**：按证书吊销，选择 RFC 5280 原因码（密钥泄露、关联变更、已取代、停止运营等）；
- **颁发机构管理 → 吊销列表**：按序列号吊销；
- **用户自助吊销**：用户在「我的证书申请」中可吊销自己的证书；订阅套餐可设置是否允许，以及吊销后是否释放额度；
- 吊销立即反映到 OCSP；CRL 按吊销服务配置的间隔重新生成。

## 5. 续期

用户在「我的证书管理」中对允许续期的证书发起续期（由证书开通模板「允许续期」控制），续期会以原主体与 SAN 签发新证书。

## 6. 管理员代用户提交申请

入口：**证书颁发管理 → 证书申请审核 → 新增申请**（操作员及以上权限）。

1. 先选择用户，再选择来源：该用户的订单、订阅，或直接按开通模板申请；
2. 主体信息与扩展信息可以选用户已有的（需已审核通过），也可以由管理员现场录入并直接审核通过；
3. 可选择"跳过审批直接签发"；选择直接申请时会生成一笔零金额订单，便于后续对账；
4. 提交记录会写入审计日志，包含代办人与所属用户；列表中同时展示用户名、订单号与证书类型。

> 代提交不改变授权边界：最终使用人仍是所选用户，证书的下载与使用权限归属该用户。
