# 业务模式与站点设置

入口：控制台 → **系统管理中心 → 全局站点设置**。

## 1. 业务模式

证书与云端智能卡的申请模式**分别**配置：

| 配置项 | 取值 | 效果 |
|---|---|---|
| 证书申请模式 | 销售模式 | 用户必须凭「已支付」的证书订单提交申请；申请向导只列出有剩余份数的订单 |
| | 自助模式 | 用户可直接选择处于启用状态、且允许"自助"的证书开通模板提交申请，系统自动生成零金额订单用于审计与额度控制 |
| 智能卡申请模式 | 销售模式 | 用户必须凭「已支付」的云端智能卡订单开卡；没有可用订单时控制台**隐藏「新建智能卡」按钮** |
| | 自助模式 | 用户可直接开卡，受「自助开卡上限」约束 |
| 自助开卡上限 | 0–1000 | 自助模式下每个用户可开通的智能卡数量（不含系统托管容器）；0 表示自助模式下也不可开卡 |
| 订单超时时间 | 1–720 小时 | 待支付订单超时自动关闭，并归还库存与优惠码次数 |
| 自助申请 SAN 限制 | JSON | 自助/订阅申请（无商品规格）时单张证书的域名/邮箱/IP 数量与格式限制 |

要点：

- 缺省为**销售模式**，最安全；
- 前端的按钮隐藏只是体验优化，**所有限制都由服务端在写入时强制校验**；
- 一个开通模板能否被自助申请，由模板自身的"可申请方式"决定：只勾"订单"的模板不会出现在自助入口，勾"自助"的才会；
- 管理员账号不受业务模式限制，可在「证书申请审核 → 新增申请」中代用户提交；
- 两种模式可并存：例如证书自助 + 智能卡销售。

### 推荐组合

| 场景 | 证书 | 智能卡 |
|---|---|---|
| 对外商业运营 | 销售 | 销售 |
| 企业内部 PKI | 自助（配合审核） | 自助（上限 1–3） |
| 试运营 / 免费试用 | 自助（免审模板） | 自助（上限 1） |

### 自助模式下的风险控制

- 为自助申请的开通模板开启「需要审批」，或只为 DV 类开通模板关闭审批；
- 通过商品规格（或站点配置 `self_san_policy`）限制每张证书可包含的域名/邮箱/IP 数量与格式；
- 通过主体模板/扩展信息模板的「人工审核」「实名认证」「验证有效期」控制身份资料的可信度；
- 定期在「证书颁发管理 → 证书申请审核 / 身份认证审核 / 全部证书管理」中巡检。

## 2. 品牌与门户信息

| 字段 | 用途 |
|---|---|
| 站点名称 / 标语 / 简介 | 门户顶栏、首页与页脚 |
| 联系邮箱 / 电话 / 备案号 / 页脚说明 | 页脚与帮助中心 |
| 帮助中心地址 | 外部文档地址（可选；平台内置帮助中心始终可用） |
| 客户端 / 驱动下载地址 | 门户「下载与接入」页；留空时页面显示「待配置」而不是无效链接 |
| 服务条款 / 隐私政策地址 | 页脚链接 |

保存后门户立即生效，无需重启。
