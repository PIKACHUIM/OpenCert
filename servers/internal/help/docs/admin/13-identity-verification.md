# 身份认证审核与自动审核接口

入口：**证书颁发管理 → 身份认证审核**。页面有三个选项卡，分别对应三类接口：邮件、域名、实名认证。

## 一、待审核（人工）

主体信息与扩展信息在「自动验证」失败、或模板要求人工审核时进入待审核队列。

| 操作 | 说明 |
|---|---|
| 通过 | 按模板的"审核有效期"计算过期时间，通过后在有效期内可直接用于证书申请 |
| 驳回 | 必须填写原因，用户可修改后重新提交 |
| 查看材料 | 展示用户提交的主体字段与域名/邮箱/IP 列表 |

## 二、邮件接口（选项卡：邮件）

用于发送邮箱验证码、证书签发通知等业务邮件。

1. 新增接口：选择驱动（SMTP / Resend），按表单填写连接参数；
2. SMTP 需填写服务器、端口、加密方式（明文 / STARTTLS / 隐式 SSL）、账号、密码、发件人；可设置超时；
3. 保存后可「发送测试邮件」验证连通性；
4. 勾选「设为默认」后，未指定接口的业务邮件都走它；没有默认接口时使用部署时配置的 SMTP。

## 三、域名验证接口（选项卡：域名）

系统内置三个开箱即用的接口，无需配置即可在校验中使用：

| 接口 | 验证方式 | 适用场景 |
|---|---|---|
| DNS TXT | 在域名下添加指定 TXT 记录 | 通配符域名、80/443 端口不可用的场景 |
| HTTP 文件 | 在网站根目录放置指定文件 | 服务器可控、80 端口开放 |
| TLS-ALPN | 443 端口按 ALPN 协议应答 | 80 端口被占用、无法放置文件 |

需要时可新建接口并调整解析服务器、记录前缀、端口、超时等参数；同一类接口可以存在多个，由扩展信息模板按需选择。

## 四、实名认证接口（选项卡：实名）

| 驱动 | 说明 |
|---|---|
| 支付宝身份验证 | 填写应用 ID、私钥、支付宝公钥等参数；用户在支付宝完成核验后由平台查询结果 |
| 微信实名（腾讯云慧眼） | 填写 SecretId、SecretKey、规则 ID 等参数；通过人脸核身完成核验 |
| 三方回调认证 | 平台把用户引导到自有认证页面，认证完成后回调本平台写入结果 |

### 三方回调认证的配置

1. 请求地址、请求方法、请求头、请求体模板：用变量占位符注入用户与主体信息；
2. 主体字段映射：把主体模板里的字段（如姓名、证件号）映射为对方要求的参数名；
3. 回调地址：保存后由系统生成并展示，复制给对方系统；该地址只能用 https 或 http；
4. 回调校验：可选"无校验 / HMAC 签名（含时间戳）/ 固定 Token"；选择 HMAC 时对方需按约定计算签名；
5. 回调内容格式与本平台返回内容格式：支持 JSON 与表单，按对方要求选择；
6. 保存后可「测试」：以示例数据走一次 dry-run，确认参数拼装与回调校验可用。

> 接口的密钥类字段加密保存，页面上不回显明文；对外请求统一 15 秒超时，响应体超过 1MB 会被截断。

## 五、在模板中引用

- **主体模板**：字段的"验证方式"选「自动接口」时，必须选择一个实名认证接口；
- **扩展信息模板**：域名/邮箱/IP 的"验证接口"从已启用的接口中选择，未指定时使用该类别的默认接口。

验证通过后按模板配置的有效期计算过期时间；过期或被驳回的信息不能用于证书申请，需重新验证。

## 六、默认接口与优先级

- 每类接口都可以设一个默认项（邮件、域名、实名各一个）；
- 业务调用顺序：模板指定的接口 → 该类默认接口 → 部署时的兜底配置（仅邮件）；
- 删除接口前请先解除模板引用，系统会拦截仍被引用的接口。
