# 商品、规格、订单与销售流程

## 一、商品与规格（销售管理 → 销售商品管理）

1. **商品**决定"卖什么"：名称、编码、分类（SSL/代码签名/邮件/文档签名/云智能卡）、卖点、是否前台可见与可售；
2. **规格（SKU）**决定"按什么价格卖"：

| 字段 | 说明 |
|---|---|
| 价格（分）、币种、服务期（月） | 定价信息 |
| 库存 | `-1` 不限；下单时**预占**，取消/超时关闭时归还 |
| 起购/限购数量 | 单笔订单的数量范围，订单份数决定可提交的证书申请张数（或开卡张数） |
| 交付方式 | 云端智能卡 / 文件下载 / 自备 CSR |
| 支持的密钥算法 | 前台可选算法（受开通模板再约束） |
| 关联证书开通模板 | 必填；决定资料要求与审批策略 |
| **SAN 限制** | 域名/邮箱/IP 数量上限、是否允许通配符、允许的 IPv4/IPv6、邮箱与域名后缀限制（单张证书生效） |

3. SAN 限制在下单时快照进订单规格，提交申请时按快照强校验；自助申请与订阅申请使用站点配置 `self_san_policy`（全局站点设置中可改）。

## 二、订单管理（销售管理 → 订单管理）

「全部订单」选项卡支持按状态与关键字（订单号/邮箱/商品编码）筛选，可执行：

- **确认到账**：未接入在线支付渠道时，财务核对线下转账后填写凭证号入账，订单随即变为已支付；
- **取消**：仅待支付订单可取消，库存与优惠码次数自动归还；
- 订单编号、商品/规格快照、金额（含优惠码抵扣）、状态、联系邮箱、用户均在列表可见。

「退款审批」选项卡处理用户提交的退款工单：通过（渠道原路退回或退回余额）或拒绝（需填写原因）。已开卡/已提交申请/已开通订阅的订单，系统会在用户侧阻止自助退款，管理员审批时请核实履约情况。

**超时关闭**：默认 24 小时未支付的证书订单会被自动关闭并归还库存（`order_expire_hours` 可配置）。

## 三、业务模式

在「系统管理 → 全局站点设置」中配置：

| 配置 | 取值 | 含义 |
|---|---|---|
| `cert_apply_mode` | `sales` / `self` | 证书必须购买后申请 / 允许自助申请 |
| `card_apply_mode` | `sales` / `self` | 智能卡必须购买后开卡 / 允许自助开卡 |
| `card_self_limit` | 整数 | 自助模式下每账号可开卡数量上限 |
| `order_expire_hours` | 1-720 | 待支付订单超时关闭时间 |
| `self_san_policy` | JSON | 自助/订阅申请的单证 SAN 限制 |

销售模式下：证书需凭已支付订单提交申请（订单份数逐张消耗）；智能卡需凭云智能卡订单开卡。前台会自动隐藏不具备条件的入口，服务端对所有写入接口再次校验。

## 四、优惠与订阅

优惠码、订阅套餐、订阅发放/终止、兑换码的配置与规则见《订阅优惠管理》。

要点：

- 用户购买套餐走正常订单与支付流程，**支付完成即自动开通额度**；
- 订阅额度申请证书生成零金额订单，按订阅额度去重计数；
- 订阅套餐的「单证有效期」必须落在对应颁发模板允许值内（保存时强校验）。

## 五、对账与审计

- 金额以分存储：`amount_cents`（应付）、`discount_cents`（优惠）、`frozen_cents`（历史冻结）；
- 消费/退款流水见 `consume_records`，支付尝试见 `payment_attempts`（渠道、交易号、状态）；
- 管理操作（确认到账、取消订单、退款审批、发放订阅等）均写入「证书审计日志」，含操作人、资源与 IP。
