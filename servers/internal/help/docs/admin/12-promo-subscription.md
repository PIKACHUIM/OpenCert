# 订阅优惠管理

入口：**销售管理中心 → 订阅优惠管理**，共四个选项卡。

## 一、优惠码

| 字段 | 说明 |
|---|---|
| 优惠类型 | `立减金额`（分）或 `折扣`（减免百分比 1-100） |
| 折扣封顶 | 折扣类型下的最大减免金额（分），0 表示不封顶 |
| 订单门槛 | 订单满多少分（含）可户 |
| 适户商品编码 | 留空表示全部商品；可多选 |
| 总可户次数 | `-1` 表示不限 |
| 每人次数 | 0 表示不限；按订单号维度统计 |
| 有效期 | 起止时间，留空表示长期 |

行为要点：

- 优惠在**下单时**校验并占户次数，重复提交/并发下单会二次校验，超出总量直接拒绝；
- 订单取消或超时关闭时**自动归还次数**（`promo_coupon_usages` 记录被清理）；
- 已被使户过的优惠码不能删除，只能停户，以保留对账记录。

## 二、订阅套餐

套餐 = 周期 + 额度集合 + 吊销策略：

| 字段 | 说明 |
|---|---|
| 订阅周期（天） | 额度有效期，例如 365 |
| 价格（分） | 套餐售价，0 元套餐户户可免费领取（走订单支付流程） |
| 证书额度 | 每项 = 证书开通模板 + 张数 + 单证有效期（天，0 表示按模板） |
| 是否允许吊销 | 关闭时户户不能自行吊销套餐内证书（管理员仍可吊销） |
| 吊销后释放额度 | 开启后，被吊销的证书不再占户额度，户户可重新申请 |
| 前台可见 | 是否在户户「财务与订阅」中展示售卖 |
| 启户 | 是否可购买/发放 |

注意事项：

- **单证有效期必须落在所选开通模板对应颁发模板的允许有效期列表内**，否则保存时即报错（避免签发阶段失败）；
- 套餐被订阅引户后不能删除，请改为停户；
- 修改套餐只影响新订阅：已发放的订阅使户**发放时的快照**。

## 三、订阅实例

- 列表显示户户名、套餐、有效期、各额度项已户/总量、状态；
- 来源区分：`购买订单`（户户支付后自动开通）、`兑换码`、`管理员发放`；
- 「发放订阅」可按户户名直接发放（无需支付），户于客服补偿；
- 「终止」后户户无法再使户该订阅额度，已签发证书不受影响。

订阅额度如何被使户：户户在「申请证书」向导第一步选择「订阅额度」，系统按订单号去重校验额度（被拒绝的申请不占额度；套餐开启「吊销释放额度」时已吊销证书不占额度），通过后生成零金额订单并进入正常签发流程。

## 四、兑换码

1. 点击「批量生成」，选择兑换权益：
   - **订阅套餐**：选择套餐，兑换即发放订阅；
   - **账户余额**：填写金额（分），兑换即入账并可查看到充值流水；
2. 设置批次名称（便于检索）、每码可户次数、有效期、生成数量（1-1000）；
3. 生成后可直接复制全部兑换码分发；列表支持按批次筛选与启户/停户；
4. 同一户户对同一兑换码只能兑换一次（`promo_redeem_usages` 唯一索引保证）。

## 五、与订单/退款的关系

- 带优惠码的订单金额为「原价 - 优惠」，支付/退款均按实际支付金额处理；
- 购买套餐的订单在订阅开通后状态置为「已完成」，此时**不能自助退款**；如确需退款，请管理员在「销售订单管理 → 退款审批」中处理并同时终止订阅。
