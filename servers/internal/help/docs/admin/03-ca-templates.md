# CA、证书模板与三层配置

## 一、证书颁发机构（证书颁发 → 证书颁发机构）

1. 创建根 CA：填写名称、密钥算法、有效期与主体信息；私钥由平台主密钥加密保存；
2. 可导入下级 CA 证书链（用于承载已在外部的 CA）；
3. 对外发布：勾选公开后，该 CA 出现在门户「信任服务」中，可被下载证书链；
4. 吊销与 CRL：吊销证书后会自动加入 CA 的吊销列表；CRL 刷新间隔在「证书服务 → 证书吊销服务」中按 CA 配置；
5. OCSP：单 CA 场景用 `/ocsp/{caUUID}`；多 CA 统一入口请使用「证书服务 → 证书OCSP服务」（见《OCSP 响应服务与证书策略》）。

## 二、三层职责划分（重要）

平台把"怎么签 / 怎么申请 / 怎么卖"拆成三层，避免同一参数在多处重复配置：

| 层 | 位置 | 负责 |
|---|---|---|
| **颁发模板**（Issuance Template） | 证书模板 → 颁发模板 | 技术签发策略：CA 候选、允许的有效期列表、允许的密钥算法、是否为 CA、KU/EKU、证书扩展、密钥存储 |
| **开通模板**（Apply Template） | 证书模板 → 证书开通模板 | 面向用户的开通规则：绑定颁发模板 + **主体模板** + **扩展信息模板**、是否人工审批、是否允许续期、可选密钥算法、指定 CA 与有效期（可留空用颁发模板缺省） |
| **商品规格**（SKU） | 销售管理 → 销售商品管理 | 商业参数：价格、库存、服务期、交付方式、可选算法、**单张证书的 SAN 数量与格式限制** |

价格与库存只存在于规格上（颁发模板上的历史价格字段已不再使用）；SNA 数量限制只在规格上（扩展信息模板不再限制数量）。

商品与开通模板的引用关系：**规格 → 开通模板 → 颁发模板**。云智能卡类商品的规格只需任选一个开通模板占位（不会用于证书申请）。

## 三、主体模板（证书模板 → 主体模板）

定义证书主体字段的填写与验证规则，字段名从预置列表选择（CN/O/OU/C/ST/L/STREET/PostalCode/SerialNumber/E/UID/Title/...）。

每个字段可配置：

| 配置 | 说明 |
|---|---|
| 必填 | 不填则跳过该字段 |
| 长度范围 | 最短/最长字符数（最长留空默认 128） |
| 格式 | 预置格式：国家代码 / 邮箱 / 域名 / 纯数字 / 统一社会信用代码；也可填自定义正则 |
| 验证方式 | 人工审核 / 自动接口（实名认证）/ 免验证 |
| 派生 | 空 / 取自第一个域名 / 第一个邮箱 / 第一个 IP。派生字段由扩展信息自动推导，**不显示给用户、无需验证** |
| 默认值、填写提示 | 表单辅助 |

模板级配置：

- **审核/认证有效期**：`1d/7d/30d/365d`、`12h` 等（`0` 表示长期有效）；通过后按此计算过期时间；
- **实名认证接口**：字段中存在「自动接口」时必选。

典型配置：

- 企业 OV：`CN`（人工）、`O`（人工）、`C`（免验证，默认 CN）、`SERIALNUMBER`（人工，统一社会信用代码格式）；
- 域名 DV：仅 `CN` 派生自第一个域名 —— 此时申请向导会跳过主体信息步骤。

## 四、扩展信息模板（证书模板 → 扩展信息模板）

按**域名 / 邮箱 / IP** 三类分别配置：

| 配置 | 说明 |
|---|---|
| 是否允许 | 关闭则该证书不接受此类扩展信息 |
| 验证方式 | 人工审核 / 自动验证 / 免验证 |
| 验证方法 | 域名：DNS TXT、HTTP 文件、TLS-ALPN；邮箱：邮箱验证码；IP：HTTP 文件（可多选，用户在向导中选择） |
| 邮件接口 | 邮箱类可指定使用哪个邮件接口（未指定用系统 SMTP） |
| 验证有效期 | 如 `1d/7d/30d/365d`；过期后需重新验证 |

> 单张证书允许的域名/邮箱/IP 数量、是否允许通配符、IPv4/IPv6、邮箱与域名后缀限制，均配置在**商品规格**上，见《商品、订单与销售流程》。

## 五、其他模板

- **密钥用途模板**：KU/EKU 组合（服务器认证、客户端认证、代码签名、邮件保护、OCSP 签名等）；
- **证书拓展模板**：CRL 分发点、OCSP 服务器、AIA、CT 服务器、EV 策略 OID；证书策略/CPS 地址可引用「证书策略管理」中发布的 `/policy/...` 页面；
- **密钥存储模板**：文件下载 / 云端智能卡 / 实体卡 / 虚拟卡、安全等级（高等级不可导出与备份）、云端备份、重新下发次数；
- **自定义 OID**：供证书拓展模板引用（扩展密钥用途、主体字段、EV 策略、ASN.1 扩展）。

## 六、配置检查清单（上线前）

1. 每个对外商品：规格 → 开通模板 → 颁发模板链路完整且均处于启用状态；
2. 开通模板已绑定主体模板与扩展信息模板（或明确使用 DV 简化流程）；
3. 主体模板中「自动接口」字段已选择可用的实名认证接口；
4. 扩展信息模板中邮箱策略已指定邮件接口（或确认系统 SMTP 可用）；
5. 规格的单张证书有效期与颁发模板允许的有效期列表一致（订阅套餐保存时会强校验）；
6. OCSP/CRL 地址已填入证书拓展模板，并在信任服务中心可访问。
