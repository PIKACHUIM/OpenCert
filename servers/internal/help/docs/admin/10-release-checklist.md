# 上线检查清单与全流程验收

## 1. 发布前检查

- [ ] `SERVER_CARD_HOST` 为对外地址，服务通过 HTTPS 反向代理访问
- [ ] `SERVER_CARD_JWT_SECRET` 为 32 位以上随机值
- [ ] `SERVER_CARD_MASTER_KEY` 已设置并离线备份
- [ ] `SERVER_CARD_BASE_URL` 与对外域名一致（支付/实名回调依赖）
- [ ] 初始管理员已改密并绑定两步验证
- [ ] SMTP 已配置并测试（找回密码、邮箱验证码）；如需分别发送可在「身份认证审核 → 自动审核」中配置 SMTP/Resend 接口并「测试」
- [ ] 至少一个中间 CA 可用，根 CA 已离线备份
- [ ] 公开 CA 已在「证书颁发机构」中打开门户公开，信任服务页可见
- [ ] 业务模式（证书/智能卡）、订单超时时间、自助 SAN 限制已按运营策略设置
- [ ] 站点设置中的联系方式、条款（可指向「证书策略管理」发布的 `/policy/...` 页面）、下载地址已填写
- [ ] 数据库自动备份与恢复演练已完成

## 2. 全流程验收

以下每个流程都应使用独立测试账号在预发布环境完整走一遍。

### A. 存储区域、用户智能卡、CRL、ACME、OCSP

1. 存储区域配置：新建「数据库」区域；
2. 站点设置：智能卡设为自助模式、上限 1；
3. 测试用户开卡（PIN ≥ 6 位）→ 第二次开卡应被拒绝，按钮隐藏；
4. 管理员「订单管理」等页面无法直接操作卡片，改用控制台「用户智能卡」（管理员视图）核对卡片与证书数量；
5. 模拟 PIN 输错 3 次 → 用户「解锁（PUK）」；再验证 Admin Key 重置 PIN/PUK；
6. 证书吊销服务：为 CA 新增 `crl`、`ocsp` 自定义路径，信任服务页显示新地址；
7. 证书OCSP服务：新增响应服务（签名者选 CA，负责该 CA），地址 `/ocsp/r/{path}` 可被 `openssl ocsp` 查询；
8. 下载 CRL，`openssl crl -inform DER -text` 可解析；
9. 签发一张证书后吊销，OCSP 返回 revoked（先试 `/ocsp/{caUUID}`，再试统一响应服务地址）；
10. ACME：新增配置，用 certbot/acme.sh 对测试域名完成一次签发。
11. 证书策略：新建 `/policy/cps` 策略并在信任中心确认可见。

### B. 用户、商品、订单、颁发

1. 用户管理：创建 operator 与 user 账号，修改角色生效；
2. 商品管理：创建 SSL 商品 + 规格（关联证书开通模板、库存 5、SAN 限制 2 个域名）与云智能卡商品 + 规格；
3. 前台可见性：未发布商品不出现在产品中心；
4. 用户下单 → 库存减少 → 取消订单 → 库存恢复、优惠码次数归还；
5. 用户下单 → 管理员「订单管理 → 确认到账」→ 订单已支付；
6. 已支付订单退款申请 → 「订单管理 → 退款审批」→ 余额/渠道/线下结果正确；
7. 对账：检查消费流水与支付尝试记录（渠道、交易号）与实际一致。

### C. CA、证书模板（三层）与 OID

1. 创建根 CA 与中间 CA，导入证书链，证书链下载完整；
2. 创建主体模板（含派生字段与人工字段）、扩展信息模板、密钥用途模板、证书拓展模板、密钥存储模板；
3. 创建颁发模板并关联以上模板与中间 CA；
4. 创建证书开通模板：绑定颁发模板 + 主体模板 + 扩展信息模板（需要审批 / 免审各一个）；尝试保存引用不存在的模板应被拒绝；
5. 在「证书模板 → 自定义 OID」新增一个 OID，并在证书拓展模板中引用。

### D. 身份认证与申请、审核、颁发

1. 用户提交主体信息（含人工字段）→ 管理员在「身份认证审核 → 待审核」中通过（检查是否写入有效期）；
2. 人工字段被驳回 → 用户修改后重新提交 → 再次通过；
3. 域名扩展信息：分别在「免验证 / 自动（DNS/HTTP/TLS）/ 人工」三种策略下创建，验证状态与有效期正确；
4. 邮箱扩展信息：配置邮件接口后接收验证码完成验证，错误验证码 ≥5 次后需重新发送；
5. 用户在「申请证书」向导提交 → 免审模板应直接签发（结果页显示证书已签发，申请详情带证书编号）；需审模板应显示「证书审核中」；
6. 超额域名（超过规格 SAN 限制）提交应被拒绝并提示数量上限；
7. 驳回路径：驳回后订单回到已支付，用户可重新提交；
8. 吊销：用户自助吊销（套餐允许时），OCSP 状态随即变化。

### E. 用户侧：选智能卡/证书 → 支付 → 申请 → 颁发

1. 门户选购 → 下单 → 收银台支付（余额或渠道）→ 支付完成页「去提交申请」；
2. 支付完成页到达申请向导，来源自动选中该订单；
3. 订阅套餐购买 → 支付完成 → 「账号信息管理 → 财务与订阅」显示额度已开通；
4. 兑换码兑换订阅与余额各一次，同一用户重复兑换被拒绝；
5. 使用订阅额度申请证书 → 额度扣减 1 张；额度耗尽后再申请被拒绝；
6. 云端使用型证书：申请时选择智能卡 → 签发后本地管理端可签名。

### F. 帮助中心与文档

1. 门户「帮助中心」可访问，用户文档齐全（含《申请与签发证书》《财务、优惠与订阅》）；
2. 管理员登录后控制台「系统管理 → 帮助中心」可见管理员文档（未登录用户访问 `/api/help/admin-docs` 应 401/403）；
3. 文档中的菜单名与实际控制台一致（避免按文档操作找不到入口）。
